# 🐳 Docker Navigator

Интерактивная шпаргалка по Docker, которая поможет быстро найти нужную команду, сохранить важное в избранное и понять сложные концепции через визуальные схемы.

[🌐 Открыть шпаргалку](https://iso-hallow.github.io/docker-navigator/)

## Возможности

- 🔍 **Мгновенный поиск** — по командам, описаниям и заголовкам
- ⭐ **Избранное** — сохраняйте важные команды (хранятся в localStorage)
- 📊 **Визуальные схемы** — CMD vs ENTRYPOINT, HEALTHCHECK, Multi-stage, Volumes
- 📤 **Экспорт** — в JSON или Markdown
- 🌓 **Тёмная/светлая тема** — по кнопке или F2
- ⌨️ **Горячие клавиши** — `/` поиск, `Esc` сброс, `F2` тема
- 📱 **Адаптивный дизайн** — работает на телефонах

## Быстрый старт

1. Откройте `index.html` в браузере
2. Используйте `/` для поиска
3. Добавляйте команды в ⭐ избранное
4. Изучайте визуальные схемы
